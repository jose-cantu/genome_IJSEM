# Project Overview 
This project runs Bakta annotation on strain PSEUDO to evaluate whether its genome contains functional evidence for simple sugar utilization.

The main biological question is whether PSEUDO has genes consistent with carbohydrate uptake and catabolism, especially because the nearby comparison taxon Lawsonibacter hominis is described as asaccharolytic. The analysis will focus on Bakta-predicted functional annotations and cross-references for sugar transporters, phosphotransferase systems, glycosidases, carbohydrate-active enzymes, and central carbohydrate catabolic pathways.

GutSMASH was not informative for this question, so this run focuses on genome-wide functional annotation from Bakta outputs. Any detected genes will be treated as genotypic evidence for metabolic potential, not direct proof of sugar utilization without phenotype or growth-assay validation.
