Note to figure out which polishing method to use I would need to implement this after hybrid assembly. 
Use the measured Illumina coverage on your Unicycler assembly to pick the mode. Compute coverage once (primary alignments only), read the per‑replicon means, then choose the bin:

Decision rule (from the Microbial Genomics benchmark "How low can you go? Short-read polishing Oxford Nanopore bacterial genome assemblies" - George Bouras 2024):

 < 5× → Polypolish --careful only
 5–25× → Polypolish --careful → pypolca --careful
 > 25× → Polypolish (default) → pypolca --careful 

### How to measure the depth you should use for the decision

1) Map short reads to the Unicycler assembly (primary alignments).
(Use primary alignments for coverage estimation; the “all‑alignments” mapping you’ll make later for Polypolish will artificially inflate depth in repeats.)

```bash
bwa-mem2 index unicycler_out/assembly.fasta
bwa-mem2 mem -t 16 unicycler_out/assembly.fasta R1.trim.fq.gz R2.trim.fq.gz \
  | samtools sort -o sr.primary.bam
samtools index sr.primary.bam
```

2) Get per‑replicon mean depth (+ a global weighted mean).
Option A — samtools coverage (fast, built‑in summary):

```bash
# per-replicon means
samtools coverage sr.primary.bam | awk 'NR>1{printf("%s\t%.2f×\n",$1,$7)}'
# global weighted mean across all replicons
samtools coverage sr.primary.bam | \
  awk 'NR>1{len=$3-$2+1; sum+=len*$7; L+=len} END{printf("global_mean=%.2f×\n",sum/L)}'
```

(meandepth is column 7 in `samtools coverage` output; use `-q 20` if you want to ignore low‑MAPQ alignments.) 

Option B — mosdepth (adds distributions you can roll up in MultiQC):

```bash
mosdepth -t 16 --by 1000 --no-per-base sr sr.primary.bam
# look at sr.mosdepth.summary.txt for per-contig mean and global mean
```

(You can also use `--thresholds 5,25` with `--by` to quantify breadth ≥5× and ≥25×.) 

3) Choose the polishing mode.

 If every replicon (chromosome and plasmids) has mean ≥ 25× → run Polypolish (default) → pypolca --careful.
 If any replicon is in 5–25× → run Polypolish --careful → pypolca --careful (global).
 If any replicon is < 5× → Polypolish --careful only (skip pypolca).
  Rationale: small/low‑copy plasmids often sit below the chromosome’s depth; you want the most conservative plan that still fixes errors across all replicons. This matches the study’s depth‑dependent recommendations and avoids false positives in low‑depth regions. ([PMC][1])

> If you really want to keep pypolca off a low‑depth plasmid but on the high‑depth chromosome, split the FASTA by replicon, run pypolca only on the high‑depth file, then `cat` the polished chromosome with the un‑pypolca’d plasmids. (Polypolish you should run on the whole assembly first.) The paper notes pypolca --careful is the most effective single polisher; Polypolish --careful almost never introduces false positives at any depth. ([PMC][1])

### Why these flags

 Polypolish v0.6.0 `--careful` ignores multi‑mapped reads, preventing false corrections in repeats when depth is scarce; at high depth, default mode is preferable because it can repair repeats. 
 pypolca `--careful` raises the support thresholds (≥ 4 alt reads and ≥ 3:1 alt\:ref), which suppresses low‑depth false positives; the authors recommend using `--careful` routinely. 

### One‑shot “tell me the plan”

```bash
min_contig_mean=$(samtools coverage sr.primary.bam | awk 'NR>1{if(min==""||$7<min)min=$7}END{print min}')
if awk "BEGIN{exit !($min_contig_mean < 5)}"; then
  echo "PLAN: Polypolish --careful ONLY"
elif awk "BEGIN{exit !($min_contig_mean < 25)}"; then
  echo "PLAN: Polypolish --careful  ->  pypolca --careful"
else
  echo "PLAN: Polypolish (default)  ->  pypolca --careful"
fi
```

That’s it: measure mapping‑based Illumina depth on the Trycycler assembly, bin it with the thresholds above, and pick the corresponding Polypolish/pypolca modes. This is exactly what the 2024 benchmark recommends and what newer automated workflows (e.g., Hybracter) implement internally.

## Pipeline Overview 

| Step | Tool Used | Why I am using this tool here in this step | 

| 1) Read QC | `fastp` (Illumina) `Filtlong` + `Porechop` (ONT) | Strips adapters / low-Q reads before assembly & Filtlong enriches for longest, highest quality Nanopore reads | 

| 2) Hybrid assembly | `Unicycler --mode hybrid` | Optimized for Illumina + Nanopore; usually closes bacterial chronosomes | Includes first-pass Racon + Pilon so plishing starts cleaner | 

| 3) Long-read polish | `Medaka` | Neural-net ONT model fixes homopolymer & indel errors. Boosts draft to ~Q40 before Illumina correction | 

| 4) Short-read polish | `NextPolish (1x) -> `Polypolish` (1x) | `NextPolish` hits 99.999 % accuracy in one pass. `Polypolish` uniquely cleans repeats other polishers miss | 

| 5) Trim & Rotate | `Circlator all` -> `Circlator fixstart` | Removes duplicated ends, confims true circle. Rotates to `dnaA` / `repA` for GenBank and pangenome consistency | 

| 6) QC metrics | `QUAST` `CheckM v1.2.2` `BUSCO` | QUAST = structural soundess (contigs, N50, mis-joins) CheckM/BUSCO = biological completeness and purity may just use CheckM... | 

| 7) Annotation | `Bakta` | Curated protein names, easy GenBank submission |

| 8) Taxonomy | `GTDB-Tk` (final FASTA) | Tree + ANI/AAI values from exact publish sequence | 

| 9) Figures | 'cgview', 'Bandage', 'fastANI' (+heat-map), GTDB tree (iTOL) | Produces the four key visuals required for most journals that want a novel isolate.
