# ANI provenance

An initial FastANI screen against GTDB-derived neighbor genomes recovered the same Marseille-P3106 neighborhood indicated by GTDB-Tk (top ANI ~97.44). However, a later stricter type-material-enforced ANI workflow failed to recover acceptable type-material neighbors automatically, so final taxonomic interpretation relied primarily on TYGS/dDDH, EzAAI, and phylogenomic reconstruction.
